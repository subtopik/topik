The messages for `topik-tabs-parent-required`, `topik-steps-parent-required`, `topik-code-group-parent-required`, `topik-quiz-parent-required` and `topik-question-parent-required` name the required parent with an example child, like `topik-columns-parent-required`. A custom component that must be nested inside one of these components gets a message that fits it, rather than one about the built-in tab, step, code tab, question or choice.
