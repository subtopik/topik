# Security policy

## Supported versions

Topik is alpha software. Security fixes go into the latest `@topik/*` release
only, so keep related packages on matching, current releases.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/subtopik/topik/security/advisories/new)
for this repository. Do not open a public issue, pull request, or discussion
for a suspected vulnerability.

Include the affected package and version, a description of the impact, and
steps or a minimal example that reproduces the issue.
